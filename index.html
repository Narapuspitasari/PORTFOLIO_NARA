🍅 Tomato Leaf Classification
Project 02 — Machine Learning & Computer Vision

Tomato Leaf Disease Classification with EfficientNet-B0

Manually identifying tomato leaf diseases is slow and error-prone for farmers, risking crop loss from late detection. Thesis research addresses this by fine-tuning EfficientNet-B0 in Python and TensorFlow/Keras, using transfer learning and data augmentation to classify disease categories from leaf images, achieving 98% accuracy on the test set.

Tech Stack
Python TensorFlow / Keras EfficientNet-B0 Machine Learning Computer Vision Data Augmentation Fine-Tuning
